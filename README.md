# Pauli-string Hamiltonian evolution

This repository contains the Erdős Institute Quantum Computing Bootcamp mini-project on explicit Pauli-string circuit synthesis, first-order Trotterization, and accumulated control errors.

The notebook follows the project in the order it was developed:

1. construct simple single- and two-qubit Pauli evolutions from elementary gates;
2. infer the general basis-change + parity construction for `exp(-i theta P)`;
3. validate the general Pauli-string compiler and measure its circuit resources;
4. introduce first-order Trotterization with `H = aX + bZ`;
5. generalize to arbitrary sparse Pauli Hamiltonians `H = sum_alpha c_alpha P_alpha`;
6. compare ideal Trotter error with systematic and random `RZ` overrotation errors.

## Qubit ordering

The project follows Qiskit's Pauli-string convention: the **rightmost Pauli character acts on qubit 0**. For example, `"XIY"` represents

```text
X_2 ⊗ I_1 ⊗ Y_0.
```

No ancillas are required for the Pauli-string evolution circuit. For Pauli weight `w >= 1`, the parity construction uses exactly `2(w - 1)` CX gates.

Install `uv` if it is not already available. The first time you set up the repository, generate and commit the lockfile, then sync exactly from it:

```bash

```

The random-overrotation experiment uses a fixed NumPy random seed for reproducibility.

## Numerical references and limitations

- Dense matrix exponentiation with SciPy is used **only as an independent small-system reference**, not to construct the quantum circuits.
- The Hamiltonian compiler assumes a real-coefficient sparse Pauli expansion with equal-length Pauli strings.
- First-order product formulas are used; higher-order Suzuki formulas are outside the scope of this mini-project.
- The random error model samples independent Gaussian perturbations to compiled `RZ` angles. It is a random-unitary control-error model, not a general stochastic quantum channel.
- Dense exact exponential references scale exponentially with qubit number and are intended only for small validation examples.
